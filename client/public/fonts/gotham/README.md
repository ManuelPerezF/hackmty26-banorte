# Gotham (licencia Hoefler&Co)

La guía de estilos web Banorte usa Gotham para títulos, botones, header, menú
y campos. No se distribuye con el repo. Si cuentas con la licencia, coloca
aquí estos archivos y `globals.css` los toma automáticamente:

- Gotham-Book.woff2   (400)
- Gotham-Medium.woff2 (500)
- Gotham-Bold.woff2   (700)

Sin ellos, la interfaz usa Montserrat Variable como sustituto.
